# Недельный отчёт по бронированиям

Скрипт на Python, который из выгрузки бронирований (CSV) собирает недельный
отчёт: брони, выручка, ночи, средний чек, доля отмен, разбивка по каналам,
топ объектов. Некорректные строки (дубликаты, выезд раньше заезда, пропущенная
сумма) исключаются и перечисляются в блоке «Качество данных».

Данные в примере сгенерированы, реальных данных в проекте нет.

## Запуск

    pip install -r requirements.txt
    python make_sample_data.py     # создаёт тестовый bookings.csv
    python weekly_report.py        # создаёт report.md

Со своим файлом: `python weekly_report.py data.csv -o out.md`.
Зафиксировать дату отчёта: `--today 2026-10-19`.

Пример готового отчёта: `report.md`.
